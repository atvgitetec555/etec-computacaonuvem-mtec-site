# Garage — Catálogo de carros esportivos

Site estático desenvolvido para a Atividade 1 de Computação em Nuvem da ETEC.

## Recursos

- catálogo de carros esportivos com imagens em PNG;
- pesquisa por nome, marca, ano e motor;
- filtros por fabricante;
- ficha técnica aberta ao selecionar um veículo;
- formulário com validação em JavaScript;
- layout responsivo para computadores e celulares.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Execução local

Abra o arquivo `index.html` em um navegador.

## Publicação

O projeto foi preparado para publicação como *Static Site* no Render, com o diretório de publicação configurado como `.`.
